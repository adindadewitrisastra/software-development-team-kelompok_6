# Project Manager

# Peran
Project Manager bertanggung jawab mengelola repository kelompok dan mengatur proses kolaborasi menggunakan GitHub.

# Tugas
1. Membuat repository kelompok di GitHub.
2. Menambahkan anggota sebagai collaborator.
3. Menentukan pembagian tugas anggota.
4. Memastikan setiap anggota menggunakan branch masing-masing.
5. Melakukan review Pull Request dan membantu proses merge.

# Kontribusi
Saya berkontribusi dalam pengelolaan repository, penyusunan README, serta koordinasi kolaborasi proyek kelompok.
