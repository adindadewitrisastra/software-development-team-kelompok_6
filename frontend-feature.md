# Front-End Developer

# Peran
Front-End Developer bertanggung jawab menjelaskan bagian antarmuka pengguna dalam pengembangan perangkat lunak.

# Tugas
1. Merancang tampilan antarmuka pengguna.
2. Menentukan struktur halaman.
3. Memperhatikan kemudahan penggunaan aplikasi.
4. Mendokumentasikan fitur yang berkaitan dengan tampilan.

# Kontribusi
Saya berkontribusi dalam perencanaan dan dokumentasi fitur antarmuka pengguna pada proyek kelompok.
