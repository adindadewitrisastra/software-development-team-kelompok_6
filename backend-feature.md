# Back-End Developer

# Peran
Back-End Developer bertanggung jawab menjelaskan proses di balik aplikasi, termasuk pengolahan data dan logika sistem.

# Tugas
1. Merancang proses pengolahan data.
2. Menjelaskan logika sistem.
3. Merencanakan komunikasi antara aplikasi dan database jika diperlukan.
4. Mendokumentasikan fitur backend.

# Kontribusi
Saya berkontribusi dalam perencanaan dan dokumentasi proses backend untuk mendukung fungsi aplikasi kelompok.
